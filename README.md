# Демо «Кухни» — ИИ-превью мебели в фото квартиры клиента

Single-file HTML-демо смартфон-приложения для мебельных производств:
менеджер выбирает модель из каталога → задаёт параметры (цвет, габариты, конструктив)
→ фотографирует стену клиента → ИИ-генерация ставит мебель в фото за минуту.

## Как открыть

| Устройство | Способ |
|---|---|
| **iPhone (Safari)** | Открыть ссылку на этот сайт — всё работает сразу |
| **Android (Chrome)** | Ссылка **или** скачать `index.html` и открыть файл напрямую — Chrome исполняет JS из локального файла |
| **iPhone офлайн** | Приложение **Documents by Readdle** (бесплатное) → скачать `index.html` → открыть из Documents. Стандартные «Файлы»/Quick Look не исполняют JavaScript |

## Возможности демо

- Каталог: 7 категорий, 11 моделей с ценами «от», поиск и фильтр
- Сборка: цвет-чипы, слайдер ширины с живым пересчётом цены, опции конструктива, свободная формулировка
- Визуал: загрузка фото → генерация (нужен ключ API) → сравнение до/после, карточка предложения

Ключ API Gemini хранится только в localStorage браузера (кнопка «Ключ» на вкладке «Визуал»).

## Техническое

Один файл, без внешних зависимостей. Проверено на WebKit (движок iOS Safari) и Chromium
(Android): 0 JS-ошибок, без горизонтального скролла, поля ввода ≥16px (нет автозума на iOS).
